# PTT 有、但 JJptt 還沒做的功能

[English](missing-features.en.md) ｜ [日本語](missing-features.ja.md)

先說結論：

- **Chrome 擴充功能版**：PTT 原本的畫面（黑底那個終端機畫面）整個都在，**PTT 能做的事，在擴充功能版都能做**，只是要用 PTT 原本的按鍵操作。JJptt 另外加的閱讀模式、FACT，是疊在上面的。
- **Android App**：App 是重新設計給手機用的畫面，不是 PTT 原本的畫面，所以只做了最常用的事。下面列出 App 還**不能**做的事，以及現在可以怎麼辦。

## Android App 能做的

先列出 App 已經能做的，免得你以為沒有：

- 登入、自動登入
- 看我的最愛（包括裡面的資料夾）、熱門看板，或直接輸入看板名稱進去
- 看文章列表、搜尋標題、作者、推文數
- 看文章、看圖、看推文，還有 FACT 的標記
- 推文（推、噓、→）
- 回文（可以選要不要引用原文）
- 發文（可以選分類）

## Android App 還不能做的

| 你想做的事 | App 現在 | 可以怎麼辦 |
|---|---|---|
| **看信、寄信**（站內信、信箱） | 沒有信箱 | 到電腦上用 Chrome 擴充功能版，在主選單按 `M` 進信箱 |
| **回信給作者**（不回文，私下回） | 只能回文到看板上 | 用擴充功能版：在文章上按 `y`，選「回信給作者」 |
| **修改自己的文章** | 沒有 | 用擴充功能版：在文章列表選到那篇，按 `E` |
| **刪除自己的文章** | 沒有 | 用擴充功能版：在文章列表選到那篇，按 `d` |
| **轉錄文章**到別的看板 | 沒有 | 用擴充功能版：在文章列表選到那篇，按 `Ctrl` + `X` |
| **看精華區** | 沒有 | 用擴充功能版：在看板裡按 `z`。只想看的話，PTT 網站（www.ptt.cc）上也看得到大部分看板的精華區 |
| **一層一層逛分類看板** | 只有我的最愛、熱門看板，或自己輸入看板名稱 | 知道看板名稱的話，在 App 首頁直接輸入就好。想慢慢逛，用擴充功能版主選單的「分類看板」 |
| **看隱藏的看板、私人看板** | 看不到。App 的文章是從 PTT 網站讀的，網站上只有公開的看板 | 用擴充功能版 |
| **改 PTT 上的我的最愛** | 在看板右上角按 ☆，可以把看板加進 App 的我的最愛，再按一次移除。這只存在手機上，不會改到 PTT 帳號裡的我的最愛，也不能排順序 | 用擴充功能版在看板列表按 `a` 加入、`d` 刪除。App 下次打開、登入時會自動把新加的看板帶進來（在擴充功能版刪掉的，App 這邊要自己按 ☆ 移除） |
| **聊天、丟水球、看好友名單** | 沒有 | 用擴充功能版 |
| **查別人的名片、上站次數** | 沒有 | 用擴充功能版：在主選單進「Talk」→「Query」，輸入帳號 |
| **改個人資料**：暱稱、簽名檔、密碼 | 沒有。App 發文、回文時不加簽名檔 | 用擴充功能版，在主選單進「User」（個人設定） |
| **投票** | 沒有 | 用擴充功能版：在看板裡按 `V` 參加投票（忘了按鍵，就按 `h` 看說明） |
| **板主的工作**：看板設定、置底、刪別人的文章、水桶 | 沒有 | 用擴充功能版 |

## 擴充功能版怎麼操作 PTT 原本的功能

- 在擴充功能版裡，閱讀模式之外的畫面，就是 PTT 原本的畫面。在閱讀模式按 `Esc` 會回到 PTT 原本的畫面。
- 按鍵和你用其他 PTT 程式時一樣。上面表格寫的按鍵，就是 PTT 本來的按鍵；忘了的話，在任何畫面按 `h` 都有說明。
- 還沒裝的話：[Chrome 擴充功能版怎麼裝](desktop.md)。
