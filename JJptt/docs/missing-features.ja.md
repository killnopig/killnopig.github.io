# PTT にあって JJptt にまだない機能

[中文](missing-features.md) ｜ [English](missing-features.en.md)

まず結論です：

- **Chrome 拡張機能版**：PTT 本来の画面（黒い端末画面）がそのまま入っているので、**PTT でできることは拡張機能版で全部できます**。操作は PTT 本来のキーです。JJptt の閲覧モードや FACT は、その上に重ねたものです。
- **Android アプリ**：アプリはスマホ向けに作り直した画面で、PTT 本来の画面ではありません。そのため、よく使うことだけに絞っています。以下に、アプリで**まだできない**ことと、今どうすればいいかをまとめました。

## Android アプリでできること

すでにあるものを見落とさないように、先に挙げておきます：

- ログイン、自動ログイン
- お気に入り（フォルダーも）、人気の看板を開く。看板名を入力して直接開く
- 記事一覧を見る。タイトル・作者・プッシュ数で検索
- 記事・画像・プッシュを読む。FACT の表示つき
- プッシュ（推・噓・→）
- 返信（元の記事を引用するかどうか選べます）
- 投稿（カテゴリーも選べます）

## Android アプリでまだできないこと

| やりたいこと | 今のアプリ | 代わりの方法 |
|---|---|---|
| **メールを読む・送る**（PTT のメールボックス） | メールボックスはありません | パソコンの Chrome 拡張機能版で、メインメニューで `M` |
| **作者にメールで返信**（看板ではなく個別に） | 看板への返信だけ | 拡張機能版で、記事の上で `y` を押し、作者のメールボックスを選ぶ |
| **自分の記事を編集** | できません | 拡張機能版で、記事一覧でその記事を選んで `E` |
| **自分の記事を削除** | できません | 拡張機能版で、記事一覧でその記事を選んで `d` |
| **記事をほかの看板に転載** | できません | 拡張機能版で、記事一覧でその記事を選んで `Ctrl` + `X` |
| **精華區（アーカイブ）を見る** | できません | 拡張機能版で、看板の中で `z`。読むだけなら、多くの看板の精華區は PTT のウェブサイト（www.ptt.cc）でも見られます |
| **分類から看板を順にたどる** | お気に入り、人気の看板、看板名の入力だけ | 看板名がわかれば、アプリのホームで入力するだけです。ゆっくり探すなら、拡張機能版のメインメニューの「分類看板」 |
| **隠し看板・プライベート看板を読む** | 読めません。アプリは PTT のウェブサイトから記事を読むので、公開の看板しかありません | 拡張機能版を使ってください |
| **PTT のお気に入りを変える** | 看板の右上の ☆ で、アプリのお気に入りに追加・削除できます。これはスマホの中だけで、PTT アカウントのお気に入りは変わりません。並べ替えもできません | 拡張機能版の看板一覧で `a` で追加、`d` で削除。次にアプリを開いてログインすると、追加した看板が自動で入ります（拡張機能版で削除した看板は、アプリでも ☆ で外してください） |
| **チャット、水球（メッセージ）、友だちリスト** | できません | 拡張機能版を使ってください |
| **ほかの人のプロフィール（名片・ログイン回数）を見る** | できません | 拡張機能版で、メインメニュー →「Talk」→「Query」でアカウントを入力 |
| **自分のプロフィールの変更**：ニックネーム、署名、パスワード | できません。アプリの投稿・返信には署名がつきません | 拡張機能版で、メインメニュー →「User」 |
| **投票** | できません | 拡張機能版で、看板の中で `V`（キーを忘れたら `h` でヘルプ） |
| **板主の作業**：看板設定、固定表示、他人の記事の削除、書き込み禁止 | できません | 拡張機能版を使ってください |

## 拡張機能版で PTT 本来の機能を使うには

- 拡張機能版では、閲覧モード以外の画面が PTT 本来の画面です。閲覧モードで `Esc` を押すと戻れます。
- キーはほかの PTT ソフトと同じです。表のキーは PTT 本来のキーです。どの画面でも `h` でヘルプが出ます。
- まだ入れていない場合：[Chrome 拡張機能版の入れ方](desktop.ja.md)。

## ほしい機能があれば

アプリで先にほしい機能は、[GitHub の Issues](https://github.com/JJptt1980/JJptt/issues) で教えてください。
