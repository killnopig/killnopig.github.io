# GB子 生成提示詞（20 組，給豆包用）

每組都先貼「共同設定」，再接那一組的內容。比例建議 1:1（方形），人放在畫面中間偏左右都可以，上半身清楚。

## 共同設定（每組前面都加這段）

```
寫實照片風格，台灣年輕女生，黑色長直髮、瀏海自然，大眼、溫柔微笑，JJptt 的看板娘「GB子」。衣服上有綠色「JJ」字樣臂章。畫質高、光線柔和、臉部清楚、不要文字浮水印。
```

## 20 組

1. 白色賽車服，一手插腰一手拿黑白格子旗，背景是賽道起跑線，傍晚夕陽，半身。

4. 坐在電腦桌前，螢幕是黑底綠字的 BBS 終端機畫面，她轉頭看鏡頭微笑，房間昏暗只有螢幕光。

8. 戴耳機坐在懶骨頭上滑手機，旁邊有貓，客廳午後陽光。
9. 穿白色賽車服在雨中的賽道，撐黑白格子圖案的傘，霓虹反光。
10. 辦公室背景，穿白襯衫加 JJ 臂章，抱著筆電，站在落地窗前，城市夜景。
11. 復古 80 年代電子遊樂場，她靠在大型電玩機台旁，粉紫霓虹燈。
12. 白色賽車服，舉起獎盃和格子旗慶祝，彩帶飄落，頒獎台上。
13. 咖啡廳窗邊，雙手捧著咖啡杯（杯上有 JJ 字樣），看向窗外，溫暖色調。
14. 在書桌前寫筆記，桌上有一台老式 CRT 螢幕顯示綠色字，懷舊房間。
15. 戴著賽車安全帽、面罩掀起露出臉，對鏡頭比讚，背景模糊的賽車。
16. 公園草地上野餐，穿淺綠色洋裝配 JJ 臂章，手拿手機自拍角度。
17. 夜晚頂樓，城市燈光背景，穿黑色賽車外套，回頭看鏡頭，微風吹頭髮。
18. 圖書館書架之間，手拿一本書和手機，表情專注，安靜柔光。
19. 新年／過年主題：紅色背景、燈籠，穿紅白賽車服，手拿紅包。
20. 綠色復古掌機風的特寫：她把淺灰色掌機舉到臉旁邊，掌機螢幕顯示「JJptt」，四色綠色背景，眨眼。
