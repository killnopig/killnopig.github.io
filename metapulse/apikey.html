申請 AI 的 API 金鑰

只有要用 AI 功能的人才需要。免費申請，大約 3 分鐘。

什麼時候需要金鑰

  • 要金鑰：拍照辨識食物、用文字描述食物、AI 飲食建議、週報的 AI 總結。
  • 不用金鑰：自己輸入食物、食物庫、斷食、服藥、運動、身體記錄、圖表、Google Drive 同步、小工具。
每個人要用自己的金鑰。用誰的金鑰，就算誰的使用量。

步驟

  1. 用手機或電腦打開 Google AI Studio，用你的 Google 帳號登入。第一次會請你同意使用條款。
  2. 按 Create API key（建立 API 金鑰）。如果問你要放在哪個專案，選預設的或建立新的都可以。
  3. 畫面會出現一長串英文和數字，通常是 AIza 開頭。按旁邊的複製。
  4. 回到 MetaPulse，到 設定 → AI 辨識食物，貼到「API 金鑰」的框裡。
  5. 按 測試連線。看到「✓ 連線成功」就完成了。

要注意

  • 像密碼一樣保管：不要傳給別人，也不要貼到群組。
  • 每台裝置各貼一次：金鑰只存在那台裝置，不會放進 Google Drive 存檔。手機 App 和 Chrome 網頁版也要分開貼。換手機或重裝 App 後要再貼一次。
  • 免費額度：一般個人使用通常夠用。如果出現「用量已滿」，通常隔天就會恢復。不用綁信用卡。
  • 不小心外流：回到同一個網頁把那把金鑰刪掉，再建一把新的，貼回 MetaPulse。
  • 申請不了：Google 帳號要滿 18 歲，有些國家或地區也還不能用。

照片和文字會從你的手機直接送到 Google 辨識，MetaPulse 沒有自己的伺服器，不會經手你的資料。
